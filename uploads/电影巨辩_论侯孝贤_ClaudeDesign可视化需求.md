# Claude Design 可视化需求：电影巨辩《论侯孝贤》

> 这份文档是交给 Claude Design 的设计需求。内容和数据全部在文档里，请只使用这里给出的信息，不要补充文档以外的事实、评价或数字。

## 0. 背景

- **节目**：中文电影播客《电影巨辩》，主持人老马（magasa）、阿吴（LOOK）。本期主题是侯孝贤，时长约 2 小时 47 分。
- **来源**：ASR 转录稿。人名、片名已人工勘误；转录稿没有说话人标注，部分观点的归属是根据上下文推断的。
- **读者**：听过或打算听这期节目的影迷。他们需要在几分钟内看懂：节目讲了什么、按什么顺序讲、两位主持人的核心论点是什么、他们怎么评价每部作品，以及一些有趣的统计数字。
- **核心论点（所有图都围绕它）**：阿吴认为侯孝贤的"自然主义"不是西方的 naturalism，而是来自道家的"自然"，也就是去掉造作与执念。他据此把侯的作品分成五个阶段，并把《咖啡时光》定为巅峰；这和主流看法不同（主流通常推《悲情城市》《戏梦人生》《童年往事》《海上花》）。

## 1. 交付物

做成一套视觉统一的信息图，每张可以单独导出。默认横版 1920×1080；标注"另出竖版"的同时出一张 1080×1440 的版本，方便发到社交平台。

| V2 | 侯孝贤创作五阶段 | P0 | 年代时间轴，影片节点按节目评价着色、按提及次数定大小 | 是 |
| V3 | 节目话题热力图 | P0 | 影片 × 节目时间（每 10 分钟）的热力矩阵 | 否 |

## 2. 视觉方向

**气质**：侯孝贤式的影像感：远景、静观、留白、克制。像一张安静的长镜头画面，而不是热闹的海报。

**版式母题**：框中框。侯孝贤常用门框、窗框把画面层层嵌套，节目里也专门讨论了这一点。可以用细线矩形层层嵌套作为版面的分区和标题框，但要克制，每页最多两到三层。

**留白**：内容区不超过画面的 65%。宁可分两页，也不要挤。

| 用途 | 色值 |

| 正文墨色 | `#2B2B2B` |

| 细线、分隔 | `#CFC6B4` |
| 强调（琥珀） | `#C07A12` |

**字体**：标题用思源宋体（Noto Serif SC）粗体；正文、标注用思源黑体（Noto Sans SC）；数字用等宽数字（tabular figures）。片名一律加书名号《》。

**不要**：
- 不使用任何电影剧照、海报、截图，不画人物肖像或可辨认的人物形象，不使用电影公司或电影节的标志。需要意象时，用抽象几何、细线、色块、纸张肌理（例如一条地平线、一扇门框、一节电车的剪影线条）。
- 不用霓虹渐变、3D、玻璃拟态、大面积纯红纯黄。
- 不自行添加文档里没有的影片、人物、奖项或评价。

## 3. 文案规范

- 观点要标注归属：明确的写"阿吴"或"老马"，不确定的写"节目认为"或"一位主持人"。附录数据里已经标好，照用即可。
- 所有提及次数都是近似值（ASR 转录有漏字串字），图上统一标"约"或在脚注说明"提及次数为近似值"。
- 人名、片名以附录为准（已勘误）。外国人名用附录里的中文译名。
- 每张图右下角加一行小字来源：`来源：电影巨辩《论侯孝贤》ASR 转录整理`。

## 4. 逐张需求

### V0 封面 / 节目信息卡

- 标题：**电影巨辩 · 论侯孝贤**
- 副标题：老马 × 阿吴 ｜ 约 2 小时 47 分
- 核心论点（一句）：侯孝贤的"自然"来自道家，不是西方的 naturalism。
- 四个关键数字（大号数字 + 小字说明）：
  - 约 **426** 次：侯孝贤本人被提及（平均每分钟约 2.5 次）
  - **18** 部：节目覆盖的侯孝贤长片
  - 约 **130** 位：节目提到的导演、作家、学者和主创
  - 约 **62** 次："自然主义"一词出现
- 构图：大面积留白，一个细线的框中框，标题放在内框里。

### V1 节目脑图

- **目的**：一眼看清节目的结构与先后顺序。
- **数据**：附录 B（`outline`）。根节点"论侯孝贤"，一级节点 5 个（开场、研究综述、核心论点、五个阶段、总评），各带时间戳；"五个阶段"下有五个二级节点，每个下面是影片。
- **要点**：
  - 一级节点上标时间戳（如 0:18）和主讲人（如"阿吴"）。
  - 影片节点按评价色编码着色（见第 2 节），图例放在角落。
  - "咖啡时光"节点要突出（琥珀色、略大），旁边加小注"阿吴眼中的巅峰"。
  - 横版用水平树（从左往右读）；竖版用从上往下的树。

### V2 侯孝贤创作五阶段

- **目的**：展示阿吴的分期和节目对每部片的评价，以及节目在哪些片上花了最多口舌。
- **数据**：附录 C（`stages`）、附录 D（`films`）。
- **图形**：横向年代轴（1980–2015）。五个阶段做成轴下方的分段色带，带阶段名；年份按真实比例排布。每部片一个圆点，位置 = 年份，**面积**正比于提及次数（最小 1、最大 32），颜色 = 评价。圆点旁标片名和一句话评语（`one_line`）。
- **要点**：
  - 2007 到 2015 年之间有八年空白，照实留出来，空白本身就是信息。
  - 在《咖啡时光》上方画一条细竖线和小字"阿吴：到底了"；在《悲情城市》旁标"外界：影响最大"，形成对照。
  - 《舒兰河上》（未完成）放在轴的最右端，用虚线圆。
  - 竖版改为纵向时间轴。

### V3 节目话题热力图

- **目的**：展示节目怎么按时间推进，哪些影片在别的段落里被反复拿来对照。
- **数据**：附录 E（`heatmap`）。16 部影片 × 17 个时间格（每格 10 分钟，最后一格是 2:40–2:47）。
- **图形**：行 = 影片（按年份从上到下），列 = 节目时间。单色渐变（背景色 → 墨绿 `#2F6F6A`），0 为空白格。格内显示数字（0 不显示）。
- **要点**：
  - 顶部加一条节目段落带（附录 A2 `segments`），让读者把热区和段落名对上。
  - 可以看出一条从左上到右下的对角线（按年代逐部讲）；用一条很淡的虚线提示这条对角线。
  - 标注三个"离开对角线"的热点：《海上花》在 2:30 段又出现 5 次（拿来和《聂隐娘》比语言与演员）；《咖啡时光》在 0:30 段出现 3 次（阿吴一开始划分阶段就宣布它是巅峰）；《童年往事》散布在 11 个时间段里，是全期最常被拿来对照的作品。
  - 可选第二张：人物 × 时间（附录 E 的 `people`），同样格式。

### V4 转折的成因

- **目的**：解释侯孝贤怎样从商业片导演变成《风柜来的人》的导演。
- **数据**：附录 F（`influence`）。
- **图形**：左侧"外因"一列、下方"内因"一组，箭头汇向中间的"侯孝贤的转折"，再指向右侧"风柜来的人 1983"。边上写关系标签。
- **要点**：外因按三条链路排列，每条用同一颜色的箭头：①杨德昌 → 帕索里尼 → 视点；②马可·穆勒 → 小津 → 学会拍现代；③朱西甯 ⇢ 朱天文 → 沈从文 → 观看的力量。朱西甯到朱天文那条用虚线（是节目的推测）。

### V5 侯孝贤身边的人

- **目的**：节目提到的合作者和友人，各自和侯是什么关系。
- **数据**：附录 G（`relations`）。
- **图形**：以侯孝贤为圆心的同心圆。内圈：编剧与理念、引路与同行；中圈：摄影与声音、演员；外圈：友人与见证者。每个人一个小圆点 + 名字 + 一行关系说明。节点按人物类别色着色。

### V6 两种"自然主义"

- **目的**：讲清阿吴的核心论点。
- **数据**：附录 H（`naturalism`）。
- **图形**：左右两栏对照，中间一条竖线，竖线上写"只是中文译名相同"。左栏"西方 naturalism（词根 nature）"自上而下 4 层；右栏"侯孝贤：道家的「自然」"自上而下 4 层。下方一条横排小表：罗西里尼 / 皮亚拉 / 卡萨维蒂斯 / 侯孝贤，各一句概括。
- **要点**：右栏底部落在"写实：重点在写；深度在表面"，用琥珀色强调。

### V7 执念图谱

- **目的**：阿吴对第四阶段的统一解读：这些片都在讲执念以及如何放下。
- **数据**：附录 I（`obsession`）。
- **图形**：五行卡片，每行三栏：影片 → 谁被执念困住 → 怎么放下。顶部一句话："摄影机开动，演员进入自然自在的世界；剧情里，角色从执念走向自在。"
- **要点**：《刺客聂隐娘》属于第五阶段，卡片用虚线框并标"第五阶段"。

### V8 三组对比卡片

- **数据**：附录 J（`comparisons`）。
- **卡片一：三位导演怎么用演员**（张艺谋 / 王家卫 / 侯孝贤），每人一栏：方法、标准、比喻或例子、代表演员。
- **卡片二：《英雄》vs《刺客聂隐娘》**，两栏：核心问题、不杀的理由、不杀的目的，最后一行"张艺谋是法家，侯孝贤是道家"（注明是节目的玩笑话）。
- **卡片三：华语导演的两端**，一条水平光谱：左端侯孝贤（东方化美学思维），右端杨德昌（西方化理性主义），中间"大部分华语导演"。李安放在光谱外，注"叶月瑜：儒化好莱坞，不宜看作两人的调和"。光谱上方小字列出"传统转化的尝试者"：朱石麟、费穆、胡金铨、唐书璇。

### V9 数据排行

- **数据**：附录 K（`rankings`）。
- 三张横向条形图：人物 Top 20（按类别着色）、侯孝贤作品提及次数（按评价着色，按年份排序而非按次数）、美学热词 Top 20（单色）。
- 条形末端标数字。脚注："提及次数为近似值；侯孝贤本人约 426 次，未列入人物排行。"

### V10 词云

- **数据**：附录 K 的人物、影片、热词数据。
- 两张：①人物与影片（不含侯孝贤，字号 ∝ 次数，按类别着色，片名带书名号）；②美学与议题热词（不含"台湾""西方"这类泛用词）。
- 词云用宋体，背景纸色，避免过度旋转（横排为主）。
